# Porsche Digest V7 Deploy

## When to Use
Deploying the V7 Porsche Digest (premium design, 8 sections, integrated market data) to Cloudflare Pages at `digest.costafamily.ai`.

## Prerequisites
- Valid Cloudflare API Token with Pages permissions
- Project directory: `C:\Users\SERVER\Hermes-Workspace\porsche-digest`
- Required files: `index.html`, `styles-v7.css`, `manifest.json`, `icon-192.png`

## Quick Deploy

```bash
cd C:/Users/SERVER/Hermes-Workspace/porsche-digest

# 1. Verify token type (must be cft_ not cfat_)
echo $CLOUDFLARE_API_TOKEN | cut -c1-4

# 2. Deploy
npx wrangler pages deploy . --project-name=porsche-digest

# 3. Verify
curl -I https://digest.costafamily.ai
```

## Token Verification

| Token Prefix | Valid for Pages? |
|--------------|-----------------|
| `cft_` | ✅ Yes |
| `cfk_` | ✅ Yes (legacy) |
| `cfat_` | ❌ No (R2/S3 only) |

## Common Errors

### Authentication error [code: 10000] or [9109]
1. Token is wrong type (cfat_ vs cft_)
2. Missing permissions
3. Wrong account

Solution: Create Custom Token with:
- Account → Cloudflare Pages → Edit
- Account → Workers Scripts → Edit
- User → Memberships → Read
